# R Project: rencana promo Threads, Instagram dan Google

Disiapkan 8 Oktober 2026. Ini draft untuk ditinjau dan diposting pemilik akun, bukan posting otomatis. Tidak ada iklan berbayar atau diskon baru yang dibuat.

## Pesan utama

Plugin Premiere Pro untuk menyusun multicam mengikuti musik: analisis beat/BPM/kandidat drop → rencana kamera → review → apply. Cocok diuji dengan footage DJ set, konser dan acara live. Editor tetap meninjau hasil. Jangan menyebut akurasi 100%, speed-up tertentu, “tanpa VRAM”, kompatibel semua OS, atau testimoni tanpa bukti.

Trial 7 hari tanpa kartu dimulai pada aktivasi plugin pertama. Google atau email/password. Lifetime sekali bayar: Indonesia Rp3.575.000; luar Indonesia US$200 tampilan, checkout final IDR di Midtrans. Satu perangkat plugin aktif per akun. Adobe Premiere Pro dan biaya provider AI opsional terpisah. Mac v2.3.11.1; Windows v2.3.11.0.

## Taktik 14 hari

Posting 3 kali per minggu sebagai eksperimen awal (6 posting total); balas 5–10 percakapan relevan per hari dengan jawaban nyata, bukan paste link. Jangan DM massal atau membajak percakapan. Meta menyarankan 2–5 posting/minggu dan mencatat kontribusi besar balasan terhadap views; angka ini bukan janji performa akun kita.

Uji slot 12:00 dan 19:00 WITA secara bergantian; belum ada bukti itu jam terbaik untuk audiens kita. Gunakan satu topic tag yang benar-benar relevan jika tersedia. Variasikan pertanyaan, tutorial, masalah nyata, dan demo footage yang Anda punya hak pakainya. Tiga posting pertama tanpa hard sell; link hanya ketika membantu. Pin posting pengenalan yang menjawab apa, untuk siapa, trial dan batasan.

## Google: konten bermanfaat, bukan keyword stuffing

Halaman utama untuk produk, /id/ untuk pembaca Indonesia, /quick-start/ untuk penggunaan pertama, /compatibility/ untuk pertanyaan versi/memori, dan panduan DJ/editing untuk use case. Canonical bersih tanpa UTM; /start/ sengaja noindex agar landing kampanye tidak menjadi duplikat pencarian. Sitemap mencantumkan halaman panduan baru.

Setelah deploy, pemilik dapat meminta indexing URL baru di Google Search Console dan memeriksa impressions, clicks, query, negara serta halaman. Jangan mengklaim ranking atau indexing otomatis. Perlu akses Search Console untuk verifikasi aktual; belum dilakukan dari rencana ini.

## Ukur hasil, bukan hanya views

Catat per content_id: views + replies di Threads Insights, link visits di Insights, pengunjung website yang teramati, demo, pricing, panduan, cek kompatibilitas, klik trial, signup submit, akun baru yang terhubung, download mulai, aktivasi trial server, checkout dibuka, pembayaran server terverifikasi. Link visits Meta tidak harus sama dengan page views website (blocker, browser in-app, bot dan kunjungan berulang).

Jalankan docs/conversion-funnel.sql hanya melalui akses owner. Jangan buka data pelanggan ke publik. Laporan mengecualikan QA; tahap opsional bisa dilewati sehingga jumlahnya tidak selalu turun berurutan. Pembayaran hanya dari tabel order server, bukan event purchase_paid browser. Pengunjung anonim yang tidak pernah login tidak bisa dihubungkan ke akun secara pasti. Tidak ada klaim angka kunjungan/revenue di draft ini.

Review hari 7 dan 14: bandingkan posting dalam rentang observasi yang sama. Jika views tinggi tetapi klik rendah, perjelas konteks/CTA. Jika klik tinggi tetapi aktivasi rendah, cek in-app Google login, installer dan kompatibilitas. Jika aktivasi tinggi tetapi pembayaran rendah, kumpulkan feedback trial tentang nilai produk; jangan langsung tambah diskon. Trial 7 hari berarti cohort terbaru belum matang untuk penilaian paid.
