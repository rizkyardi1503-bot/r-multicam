Install and activate R Project Multicam AI

By R Project · Updated October 3, 2026

Use the same account on the website and in the Premiere Pro plugin. You can purchase a lifetime license before installing the extension.

Download the public installer

Download the Windows or macOS PUBLIC v2.3.10.133 release ZIP directly from this website. Choose your operating system, extract the archive and follow the included installer instructions.

Windows PUBLIC v2.3.10.133macOS PUBLIC v2.3.10.133

Install on Windows

Save your project and close Premiere Pro. Extract the release ZIP, run SETUP-WINDOWS.cmd, and follow the included instructions. Reopen Premiere after installation.

Install on macOS

Save your project and close Premiere Pro. Extract the release ZIP, run the included .command installer, and follow the release instructions. Reopen Premiere after installation.

Create an account and purchase a license

Select Buy lifetime license on the website. New customers choose Create account, confirm their email, then return to sign in. Existing plugin customers use their current account. The lifetime price is fixed at US$200. Checkout converts it to IDR using the latest available daily exchange rate and locks the rupiah amount for your order. Review that amount before paying on Midtrans.

Use your license in Premiere

Open Window → Extensions (Legacy) → R Project Multicam AI. Sign in with the account used for your purchase. The lifetime license is activated after server verification of payment. If payment is still pending, return to the website and use Check payment.

Check compatibility before purchasing

Installation and runtime behavior depend on your Premiere version, operating system and release package. Read the installer’s included requirements and instructions. Feature availability can vary by release.
