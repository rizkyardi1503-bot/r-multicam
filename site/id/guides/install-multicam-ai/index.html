Instal dan aktifkan R Project Multicam AI

Oleh Rizki Ardiansyah, pembuat R Project Multicam AI · Diperbarui 8 Oktober 2026

Gunakan akun yang sama di website dan di plugin Premiere Pro. Kamu bisa membeli lisensi lifetime sebelum menginstal extension.

Baru di sini? Ikuti checklist singkat untuk edit pertama.

Di halaman ini

  1. Download installer publik
  2. Instal di Windows
  3. Instal di macOS
  4. Buat akun dan beli lisensi
  5. Gunakan lisensimu di Premiere
  6. Cek kompatibilitas sebelum membeli

Download installer publik

Akun R Project gratis dibutuhkan untuk men-download installer publik Windows v2.3.11.8 atau macOS v2.3.11.8. Pilih sistem operasimu, buat akun atau login, konfirmasi email kalau kamu pengguna baru, lalu download ZIP rilisnya.

Login untuk download Windows · v2.3.11.8Login untuk download macOS · v2.3.11.8

Instal di Windows

Simpan project kamu dan tutup Premiere Pro. Ekstrak ZIP rilis, jalankan SETUP-WINDOWS.cmd, lalu ikuti instruksi yang disertakan. Buka kembali Premiere setelah instalasi selesai.

Instal di macOS

Simpan project kamu dan tutup Premiere Pro. Ekstrak ZIP rilis, jalankan installer Install-macOS.command yang disertakan, lalu ikuti instruksi rilisnya. Buka kembali Premiere setelah instalasi selesai.

Buat akun dan beli lisensi

Pilih Buy lifetime license di website. Pelanggan baru memilih Create account, mengonfirmasi email, lalu kembali untuk login. Pelanggan plugin yang sudah ada cukup memakai akun mereka saat ini. Harga lifetime yang ditampilkan adalah Rp2.000.000 sekali bayar. Jumlah checkout standarnya Rp2.000.000, atau 10% lebih rendah dengan kode afiliasi yang disetujui. Jumlah akhir saat checkout ditampilkan dan ditagih dalam IDR oleh Midtrans; cek nominal rupiah tersebut sebelum membayar. Tidak ada langganan plugin berulang. Adobe Premiere Pro dijual terpisah.

Gunakan lisensimu di Premiere

Buka Window → Extensions (Legacy) → R Project Multicam AI. Klik Continue with Google (v2.3.11.2+) atau login dengan email/password yang sudah ada. Gunakan akun yang sama dengan yang kamu pakai saat membeli. Login Google akan membuka browser sistem lalu kembali ke plugin; biarkan Premiere tetap terbuka. Lisensi lifetime aktif setelah server memverifikasi pembayaran. Kalau pembayaran masih pending, kembali ke website dan gunakan Check payment.

Cek kompatibilitas sebelum membeli

Proses instalasi dan perilaku plugin saat berjalan tergantung pada versi Premiere, sistem operasi dan paket rilis yang kamu pakai. Baca kebutuhan sistem dan instruksi yang disertakan di installer. Cek panduan Premiere dan memori. Mac v2.3.11.2 dan yang lebih baru mengaktifkan mode Low Memory di perangkat dengan RAM 12 GB atau kurang, tetapi tidak menjamin performa untuk project 4K yang besar. Ketersediaan fitur bisa berbeda di setiap rilis.
