Quick setup check

Choose your configuration for guidance. This does not scan your device or install anything, and it cannot certify compatibility.

Mac M1 8 GB and Low Memory mode

macOS v2.3.11.2 and newer automatically select Low Memory mode at 12 GiB RAM or less, including Rosetta. Optional AI Vision uses one CPU decoding thread and at most 24 visual samples; timeline work uses smaller batches and a 250 ms delay. Beat/BPM/drop timing detail is unchanged. Memory estimates and preflight checks are safeguards, not a GPU-memory meter or proof that every project will fit.

For long or high-resolution multicam projects, use proxies, a shorter In/Out test range and lower preview resolution where appropriate. Save your project and close other heavy apps. Stop if memory pressure becomes severe.

Premiere and memory requirements are separate

Follow Adobe's requirements for your exact Premiere version and OS. Adobe recommends 16 GB RAM for HD and 32 GB or more for 4K on Windows, and 16 GB unified memory for Apple silicon in its current guidance. These are Adobe recommendations, not a measured R Project performance guarantee. Read Adobe's technical requirements.

What you need before the first edit

  • Adobe Premiere Pro desktop, purchased separately, with a supported OS and the extension menu available.
  • FFmpeg available through the installer or set under Advanced → Settings in the panel; local music analysis uses FFmpeg/DSP.
  • Internet for account/license checks, downloads, payment verification and public updates.
  • Camera tracks and direct readable music on A1. Cameras that are not in sync can be lined up with Sync Cameras to Music (beta, lifetime license only; not in the 7-day trial).
  • Only one plugin device active per account. Minimum versions follow each OS public release without a grace period.

Music analysis runs locally; no online AI provider or API key is needed. Podcast speaker tracking remains unavailable. The footage in the workflow video is not a performance benchmark; test speed on your own project during the 7-day trial.
