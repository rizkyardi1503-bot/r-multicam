Quick start: your first Multicam AI edit in Premiere Pro

Start with a small edit and build confidence first. You need Adobe Premiere Pro, your camera footage and readable music on A1. Test the real plugin with your own project before buying. No payment card is needed for the trial.

  1. Create your free account

    Use Continue with Google or email/password. New email/password accounts must confirm their email before downloading. Keep the same account on the website and in Premiere. Creating an account does not start the trial clock.

  2. Download and install for your OS

    Windows public v2.3.11.13 · macOS public v2.3.11.13. Save your project and quit Premiere completely. Extract the ZIP; on Windows run SETUP-WINDOWS.cmd, on Mac run Install-macOS.command. Follow the included instructions, then reopen Premiere. A DaVinci Resolve version is coming soon.

    Detailed installation guide

  3. Open the panel and activate your trial

    In Premiere open Window → Extensions (Legacy) → R Project Multicam AI. Sign in with the same account. First plugin activation starts the 7-day server-timed trial. Reinstalling or changing devices does not restart it. Internet is required for account/license checks and updates.

  4. Prepare a duplicate sequence

    Save your project and duplicate the sequence. Put each camera on its own video track. Put a direct readable WAV/MP3 or other supported music file on A1. Set In/Out for a short first test. Cameras not in sync yet? Step 2 · Sync Cameras to Music lines them up and builds a new synced sequence. It is a beta feature for the lifetime license only; it is not part of the 7-day trial.

  5. Analyze the music and set up Auto Cut

    The panel shows five numbered steps. In step 1, click Analyze Music. Check BPM, Drops, Energy and Drop score; detection can vary with the recording. In step 3 · Auto Cut Multicam, pick an Editing preset or a Cut Pace (2, 4, 6 or 8 beats), a Main Drop Camera and the cameras to use under Camera roles & cameras used. Open Preview camera plan before applying to check the plan first.

  6. Run Auto Cut, then watch the result

    Tick Save backup copy of sequence before applying, then click Run Auto Cut. If a job stops, Continue Multicam lets you resume it. Watch the full result before exporting. Then add highlight clips with step 4 · Best Drops, or movement with step 5 · Random Zoom.

Mac M1 / 8 GB?

macOS v2.3.11.2 and newer enable Low Memory mode automatically on Macs with 12 GiB RAM or less. Use proxies and a short test range where needed. Native M1 performance is not yet measured; this is not a guarantee that a long 4K multicam project will fit in memory.
