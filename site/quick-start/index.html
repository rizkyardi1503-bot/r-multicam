You need Adobe Premiere Pro, synchronized camera footage and readable music on A1. Test the real plugin with your own project before buying. No payment card is needed for the trial.

Check your setup firstTry the browser illustration

  1. Create your free account

    Use Continue with Google or email/password. New email/password accounts must confirm their email before downloading. Keep the same account on the website and in Premiere. Creating an account does not start the trial clock.

  2. Download and install for your OS

    Windows public v2.3.11.2 · macOS public v2.3.11.2. Save your project and quit Premiere completely. Extract the ZIP; on Windows run SETUP-WINDOWS.cmd, on Mac run Install-macOS.command. Follow the included instructions, then reopen Premiere.

    Detailed installation guide

  3. Open the panel and activate your trial

    In Premiere open Window → Extensions (Legacy) → R Project Multicam AI. Sign in with the same account. First plugin activation starts the 7-day server-timed trial. Reinstalling or changing devices does not restart it. Internet is required for account/license checks and updates.

  4. Prepare a duplicate sequence

    Save your project, duplicate the sequence, synchronize your cameras and put each camera on its own video track. Put a direct readable WAV/MP3 or other supported music file on A1. Set In/Out for a short first test. Enable the cameras you want to use and choose their roles.

  5. Analyze music and review the camera plan

    Run Analyze Music. Inspect BPM, beats and drop candidates; detection can vary with the recording. Generate / Revise Plan, then inspect Review Multicam / Multicam Results. Change the camera selection or plan if it does not match your intent.

  6. Apply with Keep Clips, then watch the result

    Start with Apply · Keep Clips so unused camera pieces remain in the duplicate sequence. Watch the full result before exporting. Avoid destructive cleanup until you have reviewed the plan and saved a recoverable project copy.

Mac M1 / 8 GB?

macOS v2.3.11.2 enables Low Memory mode automatically on Macs with 12 GiB RAM or less. Use proxies and a short test range where needed. Native M1 performance is not yet measured; this is not a guarantee that a long 4K multicam project will fit in memory.
